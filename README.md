# THE LAST SIGNAL // Track Omega: Mystery Box

> **"Three tabs. Three clues. One last transmission."**

A cinematic, science-fiction, multi-tab browser mystery engine built for the Frontend Vibe Codeathon.

---

## 🛰️ Overview

The player intercepts a mysterious, fractured digital telemetry transmission. Its contents are encrypted, decentralized, and distributed across three browser tabs. To breach the digital vault and uncover the truth, the player must:

1. **Terminal 1: Transmission (`/?role=transmission`)**: Analyze raw encrypted ciphertext (`VJG NCUV UKIPCN`) using an interactive offset tuner (-13 to +13, presets), live decoded stream, and final Vault Access Terminal.
2. **Terminal 2: Cipher Key (`/?role=key`)**: Initiate frequency deconvolution scanning (or manual hydrogen line tuning at `1420.4 MHz`) to isolate the Caesar rotation key (`SHIFT: 2 BACKWARD`) and broadcast it to all terminals.
3. **Terminal 3: DOM Anomaly (`/?role=anomaly`)**: Open browser DevTools (`F12`) to inspect real DOM elements:
   - `#anomaly-node` for the custom attribute `data-transmission-anomaly="SIG-7749-OMEGA"`.
   - **Surprise Challenge C1 (Plot Twist)**: Real-time `MutationObserver` on `#containment-anomaly-node`. Mutate `data-containment-protocol="RESTRICTED"` to `"OVERRIDE"` to disengage quarantine and detonate a celestial Supernova singularity burst!
4. **Temporal Security Gate**: The digital vault operates on a deterministic, synchronized cycle (`SEARCHING` → `ALIGNING` → `STABLE`). Submissions are only authorized during the **`STABLE`** frequency window.
5. **The Final Vault Reveal**: Unlocks a layered illuminated concentric mechanical dial (electric cyan, astral violet, solar amber, and emerald core) backed by a procedural **Supernova Singularity Burst Canvas**, SHA-256 verification, celebratory confetti, Web Audio synthesis, audio log voice playback, and classified dossier (.txt) export: **`THE LAST SIGNAL`**.

## 🛠️ Tech Stack & Architecture

- **React 18 & TypeScript**: Component-driven architecture with strict typing.
- **Tailwind CSS**: Custom luminous sci-fi palette (ultra-dark space `#03060d`, electric cyan `#00f0ff`, astral violet `#8b5cf6`, solar amber `#f59e0b`, neon emerald `#10b981`).
- **BroadcastChannel API + localStorage fallback**: Real-time bidirectional cross-tab synchronization with monotonic revision ordering.
- **DOM MutationObserver API**: Real-time DOM attribute watcher for hackathon surprise challenge evaluation.
- **HTML5 Canvas & KaTeX**: Procedural multi-threaded particles, gravitational physics, and starlight bursts.
- **Web Crypto API**: SHA-256 cryptographic digest validation of decrypted plaintext.
- **Procedural Web Audio API + SpeechSynthesis**: 100% self-contained audio synthesizer for tactical clicks, radar pings, supernova booms, and radio voice log playback (zero external asset files needed, completely offline, includes mute toggle).
- **Vitest**: Comprehensive test suite covering cipher logic, temporal phase calculations, verification rules, state reducers, and DOM mutation observers.

## 🎮 Multi-Tab Demonstration Walkthrough

1. Open `http://localhost:5173/`.
2. Click **"START INVESTIGATION (OPEN 3 TABS)"** (or open 3 separate browser windows):
   - Tab 1: `http://localhost:5173/?role=transmission`
   - Tab 2: `http://localhost:5173/?role=key`
   - Tab 3: `http://localhost:5173/?role=anomaly`
3. Notice the top navigation bar updates automatically in all tabs: **`REV-X (3 TABS LINKED)`**.
4. In Tab 2 (**Cipher Key**), click **"INITIATE TELEMETRY SCAN"** (or tune slider to `1420.4 MHz`). Notice Tab 1 and Tab 3 instantly update to show Key status confirmed!
5. In Tab 3 (**DOM Anomaly**), press `F12` to inspect `#anomaly-node` (`data-transmission-anomaly="SIG-7749-OMEGA"`). Enter the code and click **"CONFIRM"**. Or inspect `#containment-anomaly-node` and mutate `data-containment-protocol="OVERRIDE"` to trigger the Supernova burst!
6. In Tab 1 (**Transmission**), slide the Caesar shift offset to `-2`. The ciphertext `VJG NCUV UKIPCN` resolves to `THE LAST SIGNAL`. Click **"LOCK IN DECRYPTED SIGNAL"**.
7. In the Vault Access Terminal, wait for the temporal clock to reach **`STABLE`** (countdown is synchronized across tabs to the exact second). Submit `THE LAST SIGNAL`.
8. Watch the concentric rings spin and unlock, revealing the classified transmission and supernova!
